# Facilitating Early Maladaptive Schema–Guided Polite and Empathetic Psychotherapeutic Support: An LLM-Driven MoE-RL-Based Dialogue System

This repository contains the dataset and code for our paper titled [Facilitating Early Maladaptive Schema–Guided Polite and Empathetic Psychotherapeutic Support: An LLM-Driven MoE-RL-Based Dialogue System
]()

## Code
The folder MATE.zip contains the code for the proposed MATE framework.

## Data
The folder Sample_Dataset contains a sample of the datasets used in the work.
